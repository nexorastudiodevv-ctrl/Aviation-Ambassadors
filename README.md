# سفراء الطيران

موقع عربي لأدلة السفر والتخطيط للرحلات ومقارنة تكلفة الطيران. الأسعار والتوفر تتغير ويجب التحقق منها لدى الناقل؛ الموقع لا يعالج الحجوزات أو المدفوعات مباشرة.

## التشغيل المحلي
افتح `index.html` في المتصفح، أو شغّل خادم ملفات ثابتة من مجلد المشروع.

## النشر وظهور محركات البحث
1. تأكد من تفعيل GitHub Pages من Settings → Pages، واختر الفرع `main` والمجلد الجذر.
2. النطاق الأساسي: `https://avam.nexorastudio-eg.com/`. تحقق بعد كل نشر أن الصفحة الرئيسية و`/robots.txt` و`/sitemap.xml` تستجيب عبر HTTPS.
3. أضف النطاق إلى Google Search Console، وأرسل `https://avam.nexorastudio-eg.com/sitemap.xml`. استخدم فحص عنوان URL للتحقق من صفحات الأدلة وطلب الفهرسة بعد نشرها. يمكن إضافة الموقع أيضًا إلى Bing Webmaster Tools.
4. تضم خريطة الموقع الصفحات التي تحمل `index, follow` فقط. لا تضف الصفحات الموسومة `noindex`، وحدّث `lastmod` عند تعديل المحتوى فعلًا.
5. عند تغيير النطاق المخصص، حدّث الروابط الأساسية `canonical` و`og:url` وبيانات JSON-LD، بالإضافة إلى `CNAME` و`robots.txt` و`sitemap.xml`، ثم أعد نشر المشروع وفحص الروابط.
6. انشر أدلة أصلية محدثة بانتظام، وأضف روابط داخلية لها من الصفحة الرئيسية. راقب في Search Console حالة الفهرسة ومرات الظهور والنقرات؛ لا تضمن التهيئة الفنية ترتيبًا أو فهرسة فورية.

## نشر المقالات من Firebase Firestore
يُنشئ سير العمل صفحات HTML ثابتة كاملة لمحركات البحث من مستندات مجموعة `articles` التي حالتها `published`. يعمل تلقائيًا كل 15 دقيقة، ويمكن تشغيله فورًا من GitHub Actions → **Publish Firebase articles** → **Run workflow**. عند وجود تغييرات، تُرفع الصفحات المولدة وخريطة الموقع إلى `main` ويبدأ نشر GitHub Pages المعتاد.

### إعداد الوصول الآمن
1. أنشئ حساب خدمة مخصصًا للقراءة من Firestore، وامنحه أقل صلاحية لازمة لقراءة قاعدة البيانات (مثل **Cloud Datastore Viewer**). لا تستخدم مفتاح مالك المشروع.
2. أضف محتوى ملف JSON لحساب الخدمة في مستودع GitHub: Settings → Secrets and variables → Actions → New repository secret، والاسم `FIREBASE_SERVICE_ACCOUNT_JSON`.
3. أنشئ Fine-grained personal access token للمستودع `nexorastudiodevv-ctrl/Aviation-Ambassadors` بصلاحية **Contents: Read and write**، واحفظه كسر `PAGES_PUBLISH_TOKEN`. يلزم هذا الرمز حتى يطلق دفع الملفات المولدة سير نشر GitHub Pages.
4. تأكد من السماح لحساب GitHub Actions بكتابة تغييرات إلى الفرع `main` (Settings → Actions → General → Workflow permissions). إذا كان الفرع محميًا، اسمح لهذا المسار بالنشر أو عدّل سياسة الحماية بما يتناسب مع فريقك.
5. يمكن نشر قواعد Firestore الموجودة في `firestore.rules` باستخدام Firebase CLI بعد اختيار مشروع Firebase الصحيح: `firebase deploy --only firestore:rules --project <PROJECT_ID>`. تسمح القواعد بقراءة المقالات المنشورة فقط، وتحصر الكتابة على حسابات المستخدمين التي تحمل custom claim باسم `admin` وقيمته `true`؛ عمليات Firebase Console تستخدم صلاحيات مالك المشروع وتتجاوز قواعد العميل.

### شكل المستند
أنشئ مستندًا في مجموعة `articles`، واجعل معرّف المستند هو الرابط اللاتيني المختصر `slug` نفسه، واستخدم الحقول:

| الحقل | النوع | مطلوب | الوصف |
|---|---|---:|---|
| `slug` | نص | نعم | يطابق معرّف المستند، بأحرف لاتينية صغيرة وأرقام وواصلات |
| `title` | نص | نعم | عنوان المقال، حتى 90 حرفًا |
| `description` | نص | نعم | وصف SEO، حتى 200 حرف |
| `excerpt` | نص | نعم | ملخص بطاقة المدونة، حتى 240 حرفًا |
| `category` | نص | نعم | تصنيف ظاهر للمقال |
| `content` | نص | نعم | نص المقال بصيغة Markdown؛ تُنقّى وسوم HTML غير المسموح بها |
| `status` | نص | نعم | استخدم `draft` للمسودة و`published` للنشر |
| `publishedAt` | Timestamp | نعم | تاريخ النشر |
| `updatedAt` | Timestamp | لا | آخر تعديل؛ يُستخدم في `dateModified` و`lastmod`، وإلا يُستخدم تاريخ النشر |
| `imageUrl` | نص | لا | رابط HTTPS للصورة الرئيسية |
| `imageAlt` | نص | عند وجود صورة | وصف بديل للصورة |

مثال لقيم مستند Firestore بمعرّف `riyadh-family-trip-checklist`:

```json
{
  "slug": "riyadh-family-trip-checklist",
  "title": "دليل الاستعداد لرحلة عائلية من الرياض",
  "description": "قائمة عملية لتجهيز وثائق الأسرة والأمتعة ومواعيد السفر من الرياض.",
  "excerpt": "راجع الوثائق والمقاعد والأمتعة وخطة الوصول إلى المطار قبل الرحلة.",
  "category": "السفر العائلي",
  "content": "# قبل موعد الرحلة\n\n- راجع وثائق كل مسافر.\n- تحقق من وزن الأمتعة وشروط الناقل.\n\n## يوم السفر\n\nاترك وقتًا كافيًا للوصول إلى المطار.",
  "status": "draft",
  "publishedAt": "<Firestore Timestamp>"
}
```

لا تضع بيانات اعتماد Firebase أو أسرارًا داخل صفحات الويب أو المستودع. بعد إعداد السر، اختبر النشر بمقال تجريبي، ثم راجع صفحة `/pages/articles/<slug>.html` وخريطة الموقع في الموقع المنشور. ملفات HTML داخل `pages/articles/` مولدة تلقائيًا؛ لا تعدّلها يدويًا.
